## 🔐 Security Architecture

My development is governed by a strict **Defensive Architecture Protocol**:

```bash
# SECURITY LAYERS (in order of execution):

[LAYER 1] Input Validation    → All user inputs pass regex sanitization
[LAYER 2] Snapshot Guard      → System state saved BEFORE any modification
[LAYER 3] Thermal Watchdog    → Real-time interrupt if temps exceed threshold
[LAYER 4] OOM Protection      → Game process shielded from force-close
[LAYER 5] Full Revert Engine  → One-command rollback to pre-modification state
```

> **Zero-trust approach:** Every system path is validated. Every command is sanitized. Every modification is reversible.
